# Tic-Tac-Toe API

Веб-сервис для игры в крестики-нолики против компьютера. Компьютер выбирает ходы с помощью алгоритма **Минимакс**, поэтому проиграть ему нельзя: в лучшем случае получится ничья.

Проект выполнен в рамках обучения в Школе 21 (Python Bootcamp). Цель: потренировать многослойную архитектуру и внедрение зависимостей на небольшом, но законченном приложении.

## Возможности

- Игра с компьютером через REST API
- Алгоритм Минимакс для выбора хода
- Проверка корректности поля: нельзя изменить уже сделанные ходы
- Определение конца игры (победа, ничья)
- Несколько игр одновременно, у каждой свой UUID
- Потокобезопасное хранилище игр

## Стек

Python 3 · Flask · UUID · потокобезопасные коллекции **[уточнить: версию Python и доп. библиотеки]**

## Архитектура

Приложение разделено на четыре слоя, у каждого своя ответственность:

```
src/
├── web/          # взаимодействие с клиентом: маршруты, модели запросов, мапперы
├── domain/       # бизнес-логика: модели игры, сервис с алгоритмом Минимакс
├── datasource/   # работа с данными: хранилище, репозиторий, мапперы
└── di/           # контейнер зависимостей
```

- **domain** ничего не знает о Flask и способе хранения данных, поэтому алгоритм можно тестировать отдельно.
- **datasource** хранит игры в потокобезопасной коллекции; репозиторий скрывает детали хранилища от сервиса.
- **web** преобразует данные между форматом клиента и внутренними моделями через мапперы.
- **di** (класс `Container`) собирает граф зависимостей: хранилище (singleton), репозиторий и сервис.

## Как запустить

```bash

cd tic_tac_toe
python -m venv venv
```

## API

### `POST /game/{uuid}`

Принимает текущую игру с ходом пользователя и возвращает игру с ответным ходом компьютера.

Пример запроса **[подставьте реальный формат]**:

```json
{
  "board": [
    [1, 0, 0],
    [0, 0, 0],
    [0, 0, 0]
  ]
}
```

Пример ответа **[подставьте реальный формат]**:

```json
{
  "id": "3f2b8c1e-...",
  "board": [
    [1, 0, 0],
    [0, 2, 0],
    [0, 0, 0]
  ]
}
```

`0`: пустая клетка, `1`: ход пользователя, `2`: ход компьютера **[проверьте обозначения]**.

Если поле некорректно (например, изменены прежние ходы), сервис вернёт ошибку с описанием.

Пример вызова:

```bash
curl -X POST http://localhost:5000/game/<uuid> \
  -H "Content-Type: application/json" \
  -d '{"board": [[1,0,0],[0,0,0],[0,0,0]]}'
```

## Алгоритм Минимакс

Компьютер перебирает возможные продолжения игры и выбирает ход, который максимизирует его результат при условии, что соперник играет оптимально. Для поля 3×3 полного перебора достаточно, оптимизации не требуются.
